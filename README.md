# Joseph Andaloro | Personal Portfolio

## Overview
This portfolio showcases the body of work created by me, **Joe Andaloro**, including professional projects in art, audio, video, writing, and communications. It serves as an interactive supplement to my resume and provides a structured view of my creative and technical accomplishments.

The site was built using **HTML** and **CSS**, with a focus on clean design, accessibility, and easy navigation. It functions as a public-facing digital portfolio to present completed works and ongoing projects.

## Website
**Live Site:** [https://jandaloro13.github.io/](https://jandaloro13.github.io/)

The website is hosted via **GitHub Pages** and optimized for desktop and mobile viewing. No installation or local setup is required.

- **Video:** Directorial, cinematographic, and post-production projects.
